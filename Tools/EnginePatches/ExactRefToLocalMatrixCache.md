# Exact native reference-to-local palette memoization

CPP-only patch for the locally patched UE5.8 Engine/Private/SkeletalRender.cpp; apply after ExactComponentMatrixCache.patch. Default disabled. No Engine header ABI, shader, card or cooked asset change.

`r.SkeletalMesh.ReuseRefToLocalMatrices 0/1` selects original calculation or memoization. `r.SkeletalMesh.VerifyRefToLocalMatrices 1` independently calls the original computation on every hit and compares every output float32 byte. Any mismatch latches global failure and subsequent calls use native computation.

Cache ownership is thread local:8192 pointer-selected slots, at most32MiB retained input/output payload per worker plus slot table and reusable signature workspace. A pointer selects a slot only; it never authorizes a hit. On a hit, compare native inputs directly to the owned snapshot; do not construct/copy a signature workspace. On the first difference, retain the matched prefix and collect remaining dependency bytes for replacement. Each entry owns exact dependency bytes: source transform count, applicable leader/safe-mesh flags, source/visibility/reference/inverse array counts, active/extra bone arrays, and each actually referenced inverse bind, parent index, effective leader mapping, current OR previous transform fields, applicable visibility/leader-valid bit and fallback reference local transform. Ref-pose overrides select the effective inverse table. Current/previous inputs are independently compared. Invalid LOD and optional debug mapped-pose output bypass the cache. Hash collisions, object/allocator reuse and dynamic mutations can only hit if all numerical dependencies match.

Unchanged palettes copy cached arrays; revisions, previous-update mode, scene movement, native uploads, GPU palette replacement, normal transforms, ray-tracing extra-bone processing and VSM invalidation continue normally. No pose sharing between characters. Full-result cache must not be confused with existing per-transform conversion cache, whose early animated CPU tests had low coverage.

Control request fields: `full_ref_matrix_cache`0/1, `verify_full_ref_matrices`boolean.

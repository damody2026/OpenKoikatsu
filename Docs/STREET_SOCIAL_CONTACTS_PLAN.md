# 女角名單、導航、戀人電話與一對一

1. 右側增加可折疊女角名單，依目前runtime APNG名單產生，不寫死卡名。名單每人只一列：全名、即時距離、目前關係；先選人，再在共用操作卡顯示一次三個操作與不可用原因。共同活動／設施、觸控各自收合，聊天主選項置頂。顯示載入狀態；未就緒禁止呼叫／進入互動。
2. 導航以實際場景碰撞及共用路點做可見圖最短路徑；目標移動時重新計算，小地圖顯示金色路線及目標，不自動移動玩家、不穿牆或瞬移。路線失效顯示無法抵達，可取消。
3. 電話只允許已保存的lover關係。預約一位女孩，沿碰撞檢查路線走向玩家；玩家移動則重新尋路，近距離／視線通暢才開始原本交談。取消／逾時／關係改變／角色失效皆釋放並在當前位置恢復AI。不杜撰電話配音或增加好感。
4. 近距離且沒有未完成台詞或其他活動時，可與戀人進入自建一對一空間。保留各自APNG角色，沿用中文話題、來源語音、嘴型、表情、關係交易和現有觸控；禁止其他共同活動搶占。Esc／退出／失效恢復位置、AI、鏡頭與滑鼠，清理共用道具，不提交未完成效果。
5. 專用實景測試涵蓋非戀人拒絕、五女孩導航、電話行走／取消／到達、關係變更失效、一對一雙方還原與畫面，再完整既有功能回歸、獨立來源／語音核對，通過才更新原CMD。測試用隔離存檔及lover fixture，不修改玩家關係。

此為本作通用玩法，不冒稱原作完整電話邀請／性愛場景移植。性能驗收依使用者指示暫緩；最後完整人工操作和聽音訊驗收保留。

## 最終介面配置

左上維持小地圖；右側直排且可捲動。名單預設收起，展開後每人只有姓名／關係／距離的一列選擇鈕。選中後在名單下方顯示操作對象、不可用原因，以及唯一一組導航／電話／一對一操作。導航與呼叫中的取消入口不受名單收合影響。

交談時優先顯示雙方字幕、話題及道別／取消；共同活動／設施和觸控預設收起，活動中的退出仍保留。一對一不顯示共同活動，戀人不再顯示友誼進展／告白。長字幕和狀態文字有明確換行寬度，避免右側捲動容器將內容裁掉。

# PhysX 角色物理計畫（雙人互動次級動態）

> 2026-10-15 自 OK_Demo（`E:\PhysX\UE5.8\Samples\OK_Demo`，已退役）移入本專案。路徑與參數已改為本專案的名稱：OK_Demo → OpenKoikatsu、`Scripts/*` → `Tools/*`、`-Demo*` → `-Pair*`。整合計畫見 `Docs/PHYSX_ENGINE_PORT_PLAN.md`。

目標（使用者驗收標準）
1. 所有雙人動作，每個持續播放 10 秒，頭髮／衣服／胸部不穿模。
2. 頭抬到最高（狗爬式等）時頭髮不穿進背、肩、頸，也不穿進對方身體。
3. 隨人物移動與加速度晃動（彈跳時上下晃）。
4. 全身布娃娃可用（預設關閉，開啟後能穩定追動畫）。
5. 不影響原版 `C:/portable/OpenKoikatsu`；所有修改在 `E:/PhysX/UE5.8` 下。

架構（通用解）
- Rust `Tools/ok-extract`：DynamicBone 鏈 → `px.rs` → `OKPhysXSecondary` 外掛的 PhysX 5.11 求解。
- 身體代理：每個角色每幀依骨骼發佈膠囊（四肢、軀幹、骨盆、頸、頭、肩、上背）。
- 碰撞半徑「每幀依動畫姿勢的空隙」收縮：只擋動畫本身不會造成的穿入（晃動、下垂、甩頭），
  不用第一幀快照（姿勢一變就失效）。
- 跨角色：所有角色在同一雙人座標系，鏈也碰撞對方的身體膠囊。
- 自動稽核 `-PairAudit`：逐一播放每個雙人姿勢（取循環狀態），量 10 秒內粒子最深穿入身體膠囊的深度，
  寫入 log；以數字為準修到所有姿勢通過，再以截圖抽查。

步驟
1. 身體代理補肩／上背，空隙改依動畫姿勢（含骨段中點）每幀計算。 ✅
2. 稽核用 `PairCombo`（99 個雙人姿勢，兩人一起播）選最強循環狀態；`DebugHeadTilt` 讓頭後仰；`Tools/run_pair_audit.ps1`。 ✅
3. 跑全部姿勢，依結果修正：精確投影 ✅、非彈性接觸 ✅、碰撞體身分對應＋子步內插 ✅、跨角色座標框架 ✅。進行中：全 99 姿勢稽核。
4. 狗爬式等抬頭姿勢截圖確認。
5. 布娃娃：力驅動依承重質量、slerp 模式、慣量下限；調到穩定追動畫，截圖確認。
6. 角色世界位移（UE actor 移動）注入，讓整體移動也會晃。 ✅（`SetGroupFrame`）
7. 多張長髮女角卡片（原版 CharacterCards 唯讀）跑同一套稽核，確認是通用解。

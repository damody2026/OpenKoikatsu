# 共用一對一互動模式重構計畫

## 目標

讀卡系統與 StreetSocial 使用同一套一對一互動模式。進出模式保持同一程序、同一 World；動態載入男女高模並播放共用雙人動畫，退出後恢復各入口原有狀態。禁止另開 UnrealEditor、使用程序返回 JSON 輪詢或以隱藏的完整讀卡介面代替共用服務。

## 現況

- 讀卡互動在原程序內，但角色準備、配對目錄、播放控制與 UI 綁在 UOKGalleryWidget。
- StreetSocial 的 BeginPrivate 建立另一個 UnrealEditor 程序，透過 request/result JSON 等待返回。
- AKKPairedPlayback 已提供雙方共用時鐘、原生配對曲線與 IK，可保留並整合。

## 架構

1. 共用模式管理器：管理 Idle、Preparing、Active、Exiting、Failed，協調載入、啟用、取消與復原；入口只提供角色資料與返回操作。
2. 共用角色載入：解析卡片、服裝、目前編輯設定；背景準備男女高模、骨架及材質。角色實例與物理獨立，唯讀資源可共用。
3. 共用配對服務：從 Gallery 抽離動作目錄、背景準備、狀態切換與播放控制；男女採單一時鐘，新動作準備成功後才一起切換。
4. 動態舞台：同 World 內建立角色根節點、舞台、燈光與相機；保留來源場景，切換可見性及活動，不暫停整個 World。
5. 共用互動 UI：直接操作模式與配對服務，不搬用 Gallery 控制元件。保留相機、動作、語音、嘴型、表情、身體點觸與既有相關互動。
6. 入口轉接：讀卡保存選取、服裝、未保存編輯與預覽相機；街區保存 NPC、時間、關係、相機與輸入。互動模式不建立第二套關係存檔。

## 進入與退出

- 進入：驗證輸入 → 保存來源狀態 → 背景準備兩個高模及初始動作 → 就緒後一次切換 → 暫停來源活動並啟用互動控制。
- 載入中可取消，失敗時保留或恢復來源畫面，不替換角色。
- 退出：停止配對、語音與互動 → 取消未完成工作並使舊回呼失效 → 釋放專用角色及舞台 → 恢復來源相機、UI、輸入與活動。
- 重複退出必須安全；重複進出不得殘留角色、音訊、背景工作或無上限快取。

## 外觀與動畫

- StreetSocial 使用選中女角與當前男主來源卡；陌生、朋友及戀人皆可進入。
- 讀卡使用當前女角及選定男角，帶入未保存的體型、外觀與服裝設定。
- 保留來源高模幾何、飾品位置、光影、髮絲高光與輪廓線。
- 共用動作分類、搜尋、姿勢及階段、播放、暫停、重播、速度與體型適配。
- 尚未準備的項目顯示進度；動作切換失敗保留原可播放狀態。

## Runtime 與舊機制移除

- 正式 StreetSocial 執行檔必須具備高模及互動所需 cooked 材質、shader、動畫與載入依賴，不靠 Editor 補載。
- 移除互動用 CreateProc、TerminateProc、視窗最小化、HostedInteraction JSON 輪詢、外部凍結高模主機與啟動器驗證依賴。
- 保留診斷報告，但遊戲控制改成程序內事件。

## 驗收

1. 兩入口的模式、載入、雙人播放及 UI 為同一套邏輯；互動進出前後 PID 相同，沒有新增遊戲或 UnrealEditor 程序。
2. 男女高模、服裝、體型及外觀正確；與已確認讀卡效果比對，不能只檢查頂點數。
3. 多種配對姿勢及階段實際播放，雙方同步，切換／暫停／重播／速度正常。
4. 五位女角 × 三種關係共 15 組街區往返，位置、關係、時間、NPC 活動及控制恢復。
5. 讀卡往返保留選中卡片、男角、服裝、未保存編輯與相機。
6. 載入取消、缺失資源、快速連續切換、重複進出均能復原；沒有持續資源增長。
7. 正式 packaged StreetSocial 與 CardReaderDevelopment 入口皆通過實測，舊外部主機不是依賴。

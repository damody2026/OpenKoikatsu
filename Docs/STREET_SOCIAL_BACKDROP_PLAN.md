# 街區 runtime 遠景修正

2026-10-08，主代理直接實作。

成因：自製街區只有64×56公尺地塊，SkyAtmosphere 下半球沒有地面，平視鏡頭看見場景之外的黑色空域。

1. Runtime 從目前地面取得共用網格及材質，建立位於可行走地面下方的大面積遠景地表。無碰撞／無投影，保留既有活動、鏡頭碰撞與路徑。
2. Runtime 建立只從遠距離開始的非體積薄霧，使遠景接入天空。近距離角色不在霧起始範圍；不改角色材質、曝光或燈光。
3. 這些屬於通用場景背景，無卡片專用資產、無新增Cook材質、無KKS地圖。關卡結束釋放動態物件。
4. Development／Editor與功能回歸、新舊相同對話視角截圖比較通過後更新CMD。完整人工驗收留最後。

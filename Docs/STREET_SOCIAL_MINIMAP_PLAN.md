# 街區小地圖

以「好感度」解讀本次用語。

1. 左上角固定朝北、以男主為中心的小地圖，白色箭頭表示男主實際面向，街區路線取自目前共用路點；不額外拍攝場景或建立APNG特化資產。
2. 由runtime角色狀態列出已顯示的女角，用卡片穩定身分查關係存檔；未載入/錯誤角色不畫，超出35公尺範圍在邊緣標示，當前交談對象加白框。
3. 依當前關係階段內的實際好感值著色：負值紅、0–24灰、25–49藍、50–74綠、75以上粉；顯示中文圖例、角色編號/姓名及好感。關係升級原作會重置好感，地圖不另造計分。
4. Slate繪製時讀取最新位置與好感，因此走動、對話提交、讀檔即反映。地圖不搶鏡頭輸入，UI模式下點擊地圖不能穿透到角色觸控。
5. 專用實景probe檢查投影方向/遠距夾限、五種顏色、五女角實際繪製、UI觸控遮擋、好感即時變色與存檔不變，保存截圖；完整既有功能回歸後更新原CMD。

實作補充：文字與標記分層在路線之上。初版曾移動重疊標記，已依最後需求改為固定人物標記、僅排開姓名（見下方修訂）。Smoke02 為初期證據；最終版本及完整回歸結果見 STREET_SOCIAL_MINIMAP_VALIDATION.md。

版面依使用者修訂：小地圖左上角；人物行動、話題、設施、觸控與關係選單全部在右側直排，可捲動。

依新需求增加人名開關（預設開啟、地圖下方核取方塊）；中文5字/英文10字，中英混合以10個窄字顯示單位截取，UTF-16代理對完整保留。姓名標籤自動避讓及左右翻轉，關閉時只顯示編號/彩色標記。專用probe檢查姓名上限與實際paint名稱計數開5/關0。

## 姓名重疊修訂
人物標記固定在實際投影位置，僅移開姓名，使用同色引線連到標籤邊緣。實際字寬及字高參與避讓；標籤避開人物標記、玩家箭頭及既有標籤，並限制在地圖範圍。驗證五人同點、左/右邊緣，以及實際 Development 畫面。

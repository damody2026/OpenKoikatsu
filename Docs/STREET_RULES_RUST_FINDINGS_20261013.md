1. 換日時好感改由喜愛換算：白天累積的好感、告白失敗 −50、升階歸零都不會影響喜愛，隔天會大跳（千鶴 60→147、九十九 51→0）。喜愛低於階段區間時，每天好感都從 0 開始。

### 使用者決定（2026-10-14）與實作
1. **不要喜愛值**：好感是唯一的感情數值，換日不再重算。規則裡要問「她多喜歡他」的地方用 `Relation::liking()`（由階段與好感換算 0–100：陌生 0–35、朋友 35–65、戀人 65–100；acts.toml 的 affection 門檻也比這個）；原本加減喜愛的事件改成同比例加減好感（`add_liking`）。模型的 rel_delta 不再接受 affection，面板、提示詞不再顯示。分手改為：戀人好感降到 0 且怨氣 > 50 時依怨氣機率分手（怨氣 ≥ 90 回到陌生）。C++ 的 FOKStreetRelation 拿掉 Affection。
2. 告白失敗 −50：不改。
3. 約會：遲到每 3 分鐘扣 1 好感、最多 20；沒來扣 20（信任、怨氣照舊）。多等 60 分鐘保留。
4. **攻略難度 = 1/戀人數（最低 1/5）**：還不是戀人的她，自由對話的好感增加乘上 1/（他其他戀人的數量）（mind.rs `favor_gain`）；扣分不縮放，戀人自己不縮放。目前只套用在自由對話（主要的好感來源）；話題、活動、送禮的加分尚未縮放。
5. 名字依原作改為「凶鳥 狂死香」：`StreetSocialData/name_overrides.json`（依卡片 id）由 prepare_street_social_selection.py 套用；persona、Profile、測試資料同步。

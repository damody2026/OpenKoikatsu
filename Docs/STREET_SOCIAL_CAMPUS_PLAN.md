# StreetSocial 大學校園擴建計畫

日期：2026-10-11
狀態：已實作（HeroineMind39）。

## 決定

| # | 決定 |
|---|---|
| C1 | 校園是街區外新增的一塊區域，現有街區、商店、宿舍、圖書館都保留 |
| C2 | 校園配置參考使用者提供的「無障礙設施位置圖」：大門在南、宿舍在北、運動區在西，中間是教學區和兩塊大草坪 |
| C3 | 每個學院一棟 5 層樓的大樓；每層都可以走進去，教室共用同一套樣板；每棟都有電梯和樓梯 |
| C4 | 科系不必全部都有，但八個學院都要有；每個系有自己的系辦公室 |
| C5 | 系辦公室可以處理入學考、轉系、休學／復學、申請成績單 |
| C6 | 所有人都有智力。考試不用真的考，直接用智力算出成績；讀書會提高智力 |
| C7 | 一學期被當的科目超過一半就退學 |
| C8 | 和女主一起讀書，兩人的智力都會增加；男主智力高（≥ 75）時，女主增加的速度提高 200%（變成 3 倍） |
| C9 | 每位女學生都讀某個科系；大學不必天天上課，但上課時間要偶爾去 |
| C10 | 只顯示女主，不顯示其他學生和老師 |
| C11 | 男主固定讀資訊工程系（電資學院），之後可以在系辦公室轉系 |
| C12 | 原本街上的「學校」改成「舊校舍（社團大樓）」，保留原有活動，也可以讀書；有學籍的女主不再去那裡上課 |
| C13 | 街區裡的兩棟宿舍是學校的「校外女生宿舍／校外男生宿舍」，留在原位不搬進校園：女主的住處 id（`girls_dorm`、`boys_dorm`）和現有存檔都不變 |

**其他校園地點：**

- **行政大樓（AD）：** 在校門旁。1 樓有三個櫃台：註冊組（任何科系的入學考）、教務處（轉到任何科系）、學務處（休學、復學）。
- **校門：** 在校園南邊的入口，石柱上掛著校名「星街科技大學」，旁邊有警衛亭和校園地圖，可以合照。
- **運動場：** 在教學區西南方，跑道圍著足球場，旁邊有三座籃球場和看台。可以坐在看台聊天，或一起做伸展運動。

**每棟大樓：**

- 5 層樓；1 樓有大廳、各系系辦公室、電梯和樓梯；2–5 樓各有走廊和 4 間教室。
- **電梯：** 沿用現有的電梯系統，可以直接到任何一層。
- **樓梯：** 每層的樓梯口有一個「上樓／下樓」點，按下按鈕移動一層，畫面會短暫淡出再淡入。
- **教室編號：** 「代號＋樓層＋序號」，例如 EE-301。

## 學期與課程

- **學期：**
  - 上學期：9 月第二週的星期一開學，1 月中結束。期中考週在 11 月初，期末考週在 1 月中。
  - 下學期：2 月第四週開學，6 月下旬結束。期中考在 4 月中，期末考在 6 月下旬。
  - 其他時間是寒暑假。
- **課程：**
  - 每個系每學期有 6 門課：4 門系上的專業課，2 門通識課（在 T1 上）。
  - 每門課固定在每週某一天的上午（09:00–12:00）或下午（13:30–16:30），在某間教室上。
- **出席：**
  - 上課時間站在該教室所在的大樓裡，就算出席。
  - 大學不點每一堂名，但出席率會影響成績。
- **女主上課：**
  - 女主的日程會照她的課表去上課，但不會每堂都去，平均約 70%。
  - 出席機率由能力值和好勝心決定；心情「低落」或「疲倦」時會降低。
  - 肚子很餓或精力很低時，她會先去吃飯或休息，那堂課就算缺席。
  - 去上課時，她會走到那棟大樓、那一層的教室。

## 智力與成績

- **智力（0–100）：**
  - 男主開局 55。
  - 女主由人物設定產生（LLM 給 `intelligence`）；舊的設定由能力值和個性推算。
- **考試：** 期中考和期末考時，每門課的分數由下面三項算出：
  - 智力 × 0.7
  - 出席率 × 20
  - 基本分 15
  - 運氣 −8 到 +8
  - 這樣智力 55、出席七成的一般學生平均約 67 分；智力 30 以下大多不及格。原本的「智力 × 0.75 ＋ 出席率 × 20」會讓開局智力 55 的人全勤也有約三成機率被退學，太嚴。
  - 期末成績 = 期中 40% + 期末 60%。低於 60 分不及格。
- **退學：** 學期結束時，不及格的科目超過一半就退學。
  - 男主被退學後，可以在系辦公室或註冊組重新報考入學考。
  - 女主被退學後，下學期開學會自己重考：先考原本的系，沒考上就改考門檻最低的系；結果會寫進她的記憶。
- **讀書：**
  - 在圖書館、宿舍、教學大樓、咖啡廳可以讀書，每讀一個遊戲小時智力 +0.6。80 分以上增加的速度減半。
  - **女主自己讀書：** 學期中，有些晚上她會到圖書館或回宿舍自習（19:00–21:00）。好勝心和能力值越高越常讀；考試週和考前一週幾乎每天讀，而且讀到 22:00。自習時她會坐著看書。
  - **一起讀書：** 和女主一起讀書，兩人都會增加智力。男主智力 ≥ 75 時，女主增加的速度 ×3（+200%）。這也算一次互動，會寫進她的記憶。

## 系辦公室

在各大樓 1 樓的系辦公室，打開「系辦公室」對話框：

| 事務 | 規則 |
|---|---|
| 申請成績單 | 顯示每學期每門課的期中、期末、總成績和出席率 |
| 休學／復學 | 休學期間不用上課、不會被當；復學從下學期開始 |
| 轉系 | 學期中和寒暑假可以申請，考試週不受理；轉系考試用智力計算（智力 + 運氣 ≥ 目標系的門檻）。在教務處可以轉到任何科系 |
| 入學考 | 沒有學籍或被退學時可以報考；通過就入學 |

## 實作

- **規則與資料：** `Source/OpenKoikatsu/OKStreetSocialCampus.h`，純函式：學院、科系、課表、學期日曆、成績計算。
- **場景：** `OKStreetSocialCampus.inl`，負責上課出席、考試結算、讀書、系辦公室 App、女主上課日程。
- **模型：** `Tools/street_models/campus.py`，八棟五層學院大樓、行政大樓（`campus_ad`）、校門（`campus_gate`）、運動場（`campus_sports`）；草坪和地面在 `OKStreetSocialPlaces.h`。
- **存檔：** `relationships.json` 新增 `academics`：`player` 是男主的學籍，`heroines` 以女主 id 為鍵。每筆學籍包含科系、狀態、學期、課表、歷年成績和智力。
- **人物設定：** `ok_mind` 的 profile 新增 `department`（科系 id，只有學生才有）和 `intelligence`。舊的設定沒有這兩個欄位時，遊戲會從她的 id 和能力值推算。
- **女主日程：** 有學籍的女主不再套用舊的「上學」區塊，改依課表在上課日加入 `class` 區塊，地點是該大樓的 `classK_R` 教室。教室在樓上時，她先走到大樓門口，到了再進教室。
- **樓梯：** 站到 `stairK` 樓梯口時，右側出現「樓梯：上樓／下樓」按鈕；同行或約會中的女主一起換樓層。
- **讀書：** 每 15 個遊戲分鐘結算一次並存檔，停止讀書時把剩下的時間也結算。
- **開發驗證：**
  - `OK_STREET_UI_PROBE=campus` 搭配 `OK_STREET_START_PLACE=campus_ee@office_csie`：驗證系辦公室、成績單、休學／復學、讀書和課表。
  - `OK_STREET_UI_PROBE=stairs` 搭配 `campus_ee@stair1`：驗證上下樓。
  - `OK_STREET_UI_PROBE=admin` 搭配 `campus_ad@office_aa`：驗證教務處轉系。
  - `OK_STREET_UI_PROBE=term` 搭配 `OK_STREET_START_DAY=YYYY-MM-DD` 和 `OK_STREET_START_CLOCK=HH:MM`：從上課日或考試週五下午開始，跳過幾小時，確認出席或成績有結算；結束時在存檔旁寫出 `inspect.json`。
    - `OK_STREET_START_DAY` 會改動存檔的日期，只能用在測試用存檔，或先備份。跳日期時，所有女主的需求值會重設成早上的狀態，不會因為跳過的天數而餓壞、累壞。
  - 自動測試：`OpenKoikatsu.StreetSocial.Campus.*`（學期日曆、課表、成績與退學機率、讀書與存檔）。
  - 女主被放進教室或自習地點時，日誌會寫 `Street class:` / `Street study:`。

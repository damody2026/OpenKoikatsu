# 街區交流 Demo 操作

啟動專案根目錄的 StreetSocial.cmd。此入口是一男五女的獨立自製街區；CrowdRoom100.cmd 是原百人房間（原名 CrowdRoomDevelopmentAPNGGPU.cmd）。

- WASD 移動、Shift 跑步；鏡頭模式下移動滑鼠轉動鏡頭，游標鎖定視窗中央，滾輪調整距離。Ctrl 或滑鼠中鍵切換 UI 模式，顯示游標操作按鈕；離開遊戲視窗會釋放滑鼠，返回後恢復模式。
- 靠近已載入的女孩，提示會寫出目前對象的姓名。按 E 只和這個人搭話，先播放開場招呼。
- 範圍內同時有多位可交談的女孩時，提示會多寫「Tab 切換」。Tab 依鏡頭優先的固定順序循環；被選定的人會保持，直到她離開可交談範圍或這次交談結束。鏡頭轉向不會偷偷改掉已選定的人，也不會在按下 E 時改和提示上不同的人說話。
- 1 日常、2 戀愛、3 性愛話題；也可使用畫面上的話題／分支選項。
- 在街上靠近話題拾取物，看到名稱提示後按 F 收集；共有48種，每種每天可拾取一次，持有上限99。N 次日刷新拾取點與交談額度。
- 交談中按4或「請她選話題」，聽完女生題目後從持有話題袋選答案；相同／同類／不相干的答案有不同反應，也可「敷衍帶過」。主動選擇袋中話題同樣可聊天。話題只有完整播放且存檔成功才消耗，取消或失敗不消耗。
- Ctrl／中鍵進入 UI 模式後，可點女角的頭、臉頰、雙手、雙胸，或使用部位按鈕；可切換觸碰／注視，注視不支援手部。UI面板內的左鍵不會同時點到後面的角色。觸碰可以中止原聊天，只有新反應完整播完才保存效果與扣一次交談額度。
- 缺少原始語音的反應會顯示獨立提示，不蓋掉正在播放的字幕或扣額度；下一次互動會繼續反應次數，不借用其它聲音。
- L 切換中文／日文語音；播放台詞、等待女生題目的答案、未完成話題、觸碰反應或關係對話時不能切換。切換不會重置進行中的交易。
- Esc 中止交談。未完成話題／等待回答／關係預覽時，結束按鈕顯示「取消」並丟棄未提交結果；待機時顯示「道別」，播放完成後恢復走動。
- N 在未交談時開始次日，恢復交談額度並保留關係。
- L、1～4與N等遊戲快捷鍵只在遊戲視窗前景有效；切換到其他程式不會誤操作交談或次日。

台詞依角色性格、關係與原資料條件選取，配合相同台詞的語音與字幕。好感不是每句固定增加：正面、負面及婉拒都有各自效果。開場／道別不加分；音訊完成且存檔成功後才提交話題結果，取消不提交。

關係保存在 Saved/StreetSocial/relationships.json，不回寫 APNG。朋友／戀人透過關係事件推進，不是好感達標就自動成立。卡片搬移或改名但内容不變不會更換身分；修改卡內容時需要明確重新關聯。

功能測試及當前限制見 STREET_SOCIAL_TOPICS_TOUCH_VALIDATION.md；正式 GUI、人工聽音訊、長時間與完整性能驗收尚未用自動測試冒充完成。

女孩在共用活動點停留時會保留原活動；交談期間暫停，結束後恢復。有其他人在使用的停靠點會等待空出。這不是新增坐姿或視線 IK 動作。活動功能驗證見 STREET_SOCIAL_ACTIVITY_VALIDATION.md。

告白及友誼事件在完整對話結束後直接套用結果並自動保存，關係勾選同步更新，不需要額外確認。成功告白成為戀人，拒絕維持原關係；中途取消或語音失敗不提交。語音或動作準備失敗會釋放交談角色並顯示獨立重試提示；再次有效按 E 搭話後提示清除。錯誤技術原因記錄在遊戲 log，不將內部路徑顯示成台詞。修正與證據見 STREET_SOCIAL_RECOVERY_VALIDATION.md。

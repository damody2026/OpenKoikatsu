# 街區：攻略中提到、但遊戲裡還沒有的活動與地點

攻略第三輪（2026-10-19～21，十位新女主；遊戲內 9/1～9/19）對話裡，玩家（我）或女主提到、但街區目前做不到的東西。對照的是 `Content/IndependentResources/StreetSocialData/catalog.json` 的地點與品項，以及現有的共同活動。
已經有的（不用做）：水果店 `fruitshop`、水族館 `aquarium`、溫泉 `onsen`、神社 `shrine`、豚骨拉麵（百貨美食街）、數位相機（百貨）、拍照、牽手散步、一起喝飲料。

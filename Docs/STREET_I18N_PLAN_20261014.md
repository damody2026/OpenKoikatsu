# StreetSocial 多國語言與在地化價格計畫（2026-10-14）

目標：支援 **繁體中文（zh-TW）、簡體中文（zh-CN）、英文（en）**；日用品等價格依市場設定 **新台幣（TWD）、人民幣（CNY）、美元（USD）**。價格是**在地化的價位**，不是匯率換算：例如飯糰 NT$30 → US$1.99 → ¥5。

---

## 0. 使用者決定（2026-10-14）與因此調整的設計

1. **台灣、中國、美國三個地區都完整支援**：「地區」決定場景、價格、制度，不只是幣別。
2. **英文版連場景一起換成美國**：地名、學校與學制、店名、稅制都依地區。語言和地區可以分開選；預設配對是 zh-TW↔台灣、zh-CN↔中國、en↔美國。
3. **物價用 2010 年**（各地區 2010 年的水準）。
4. **翻譯交給 Haiku 子代理**（Agent 工具指定 haiku），不需要 API 金鑰。流程：
   - `Tools/i18n_extract_dialogue.lua` 把文字切塊；
   - 每塊由一個子代理照 `INSTRUCTIONS.md` 翻成 zh-CN（中國用語）與 en（美國場景）；
   - `Tools/i18n_check_dialogue.lua` 驗收（key 齊全、佔位符 `[H名]` 等沒掉、JSON 合法），不合格的重派。

由此調整的設計：
- **金額單位**：存檔金額用「該地區貨幣的最小單位」存整數。台幣、人民幣以「元」為單位（不變，現有人民幣存檔不需要轉換），美元以「分」為單位（$1.99 存 199）。換算只在顯示時做。
- **現有存檔**：維持「中國」地區（目前就是 CNY）。
- **制度不是選做**：三個地區各一套稅、保險、學費、最低工資等參數與規則（台灣勞健保與綜所稅、中國社保公積金與個稅、美國 FICA 與聯邦稅），原本的 P6 改成必做。
- **地區資料**：新增 `StreetSocialData/Regions/{TW,CN,US}/`，放地名與店名對照、學校、價位梯、購物籃、固定費用、收入、稅制參數；規則用目前地區的那份。

## 2. 設計決策

### 2.1 語言與市場分開設定
- **語言（locale）**：zh-TW／zh-CN／en，可以隨時切換（介面、字幕、她說話的語言）。
- **市場（market）**：TWD／CNY／USD，**開新遊戲時決定**，存在存檔裡；預設跟著語言（zh-TW→TWD、zh-CN→CNY、en→USD），也可以另外選。
- 存檔中途改市場：所有金額按「購物籃比例」重新換算（見 2.4），不用匯率。

### 2.2 一套文字表，Rust 和 C++ 共用
- 新增 `Content/IndependentResources/StreetSocialData/Localization/{zh-TW,zh-CN,en}/*.toml`，以 key 對應文字，支援參數（`{name}`、`{amount}`）。
- **ok-rules 負責載入與格式化**（新增 `i18n` 模組）：
  - 規則回傳的通知、紀錄、台詞，改用 key＋參數，由 Rust 依目前語言組成句子。
  - 她的記憶與觀察用**當下的遊戲語言**寫入（會餵給模型）。
- C++ 開場時向規則要整張表（`text_table` 規則）並快取，介面用 `OKText(TEXT("key"), Args)` 取字；跟著 `rules reload` 一起熱更新。
- 不用 UE 的 Localization Dashboard：本專案的字串幾乎都是執行期 Slate 組字，且規則端也要同一份文字。
- 驗證工具：缺 key 偵測、參數不一致偵測、偽語系（拉長 40% 的假英文）找版面溢出；並用 CI 的 grep 禁止 StreetSocial 原始碼新增中文字串（開發工具除外）。

### 2.3 繁簡不是轉碼而已
- **以 zh-TW 為來源**，zh-CN 先用 OpenCC（tw2sp，含詞彙轉換）產生，再人工校對用語表（計程車→出租车、捷運→地铁、便利商店→便利店、機車→摩托车、網路→网络…）。
- 產生後的檔案存進 repo（可審閱），**執行期不做轉換**。
- DeepSeek 回覆：zh-TW 照舊轉繁；zh-CN 轉成簡體（zh-Hans）；en 不轉。

### 2.4 價格：在地價位表，不是匯率
- **catalog 的價格改成依市場分開**：
  `price: {"TWD": {"": 30}, "CNY": {"": 5}, "USD": {"": 1.99}}`
- **價位梯（price ladder）**：每個市場一條常見售價階梯，品項標一個「階」，生成工具把階對應到各市場的價位；個別品項可以手動覆寫。
  - TWD：10, 15, 20, 25, 30, 35, 39, 45, 49, 55, 59, 65, 69, 75, 79, 85, 89, 99, 109, 120, 129, 150, 169, 199, 249, 299…
  - CNY：2, 3, 4, 5, 6, 8, 10, 12, 15, 18, 20, 22, 25, 28, 30, 35, 38, 45, 48, 58, 68, 88…
  - USD：0.99, 1.29, 1.49, 1.79, 1.99, 2.49, 2.99, 3.49, 3.99, 4.49, 4.99, 5.99, 6.99, 7.99, 8.99, 9.99, 12.99…
- **參考購物籃**（校正各市場水準用，故事設定是 2010 年，所以用 2010 年的物價）：超商飯糰、瓶裝飲料、咖啡、便當／定食、拉麵、電影票、手機月租、房租、學費、時薪。
- **購物籃比例**：用購物籃算出各市場之間的「生活物價比」，例如 TWD:CNY:USD ≈ 30:5:2，用於：
  - 存檔換市場時換算現金與存款；
  - 沒有手動定價的數值（獎勵、借款上限、她的零用錢）做初始值。
- **金額單位**：以地區貨幣的最小單位存整數（台幣、人民幣是元，美元是分）。Rust 新增 `Currency`（代碼、小數位、符號、格式），規則裡寫死的金額全部改成讀地區資料（見第 0 節）。
- **顯示格式**：NT$30、¥5、$1.99；千分位與小數依市場決定。

### 2.5 經濟制度依市場分層處理
日用品價格只是第一層，不同市場還牽涉到：
1. **固定費用**：學費、宿舍費、房租、手機月租、交通 → 依市場各一組數字（資料檔）。
2. **收入**：打工時薪、零用錢、她們的收入 → 依市場（2010 年水準：台灣基本時薪 NT$95、上海 ¥9.4、美國 $7.25）。
3. **制度**：所得稅、社會保險（台灣勞健保／中國社保公積金／美國 FICA）、銀行利率、貸款、彩券、股市 → 建議先做「同一套簡化制度、參數依市場」，之後有需要再做各國完整制度。

### 2.6 給模型的提示詞與人物
- 提示詞全部移到文字表的 `prompts/` 區，依語言各一份；指示模型「用 {language} 回答」。
- persona：zh-CN 由 zh-TW 轉換後校對；**en 需要翻譯人物設定**（約 1,100 字，模型輔助翻譯後人工校對），並確認英文時個性不跑掉（口癖如狂死香的「在下」「閣下」要找英文的對應風格）。
- 規則中的關鍵字比對全部改成依語言的清單：吹牛／過／張數與點數（"call", "bluff", "pass", "two sevens"）、各付各的（"split", "dutch"）、請客（"my treat"）、邀請字眼、地點名稱與別名、人物名稱與別名（日代千鶴／日代千鹤／Chizuru）。

### 2.7 原作台詞、語音、字型
- 原作 9,840 句＋話題 2,400 句：zh-CN 由繁體轉換後校對；**en 要新翻譯約 12,000 句**，是整個計畫最大的工作量（建議模型批次翻譯＋抽樣校對＋玩家回報機制）。
- 原作日文語音保留，字幕跟著語言；中文配音（zh_ogg）只在 zh-TW／zh-CN 使用；en 用日文原音＋英文字幕，或 TTS 英文。
- TTS：Qwen3-TTS 支援英文與簡體，但每位角色的聲音設計提示要依語言調整；要先試聽確認音色一致。
- ASR：確認 ok-asr 的模型是否支援英文與普通話（簡體輸出）；不支援就換成多語模型（例如 Whisper／SenseVoice 的多語版本）。
- 字型：繁中 Noto Sans TC、簡中 Noto Sans SC（同一個字的字形不同，不能混用）、英文 Latin；Slate composite font 依語言切換。

## 4. 需要決定的事

1. **現有存檔的市場**：目前是 CNY。要保留 CNY，還是依語言改成 TWD（按購物籃比例換算）？
2. **場景是否跟著市場變**：英文版仍是「台灣的大學城」（只換語言與價格），還是改成美國場景（地名、學制、稅制都改）？目前建議：場景維持台灣，只做語言與價格在地化。
3. **物價年代**：故事是 2010 年，各市場用 2010 年的價位（飯糰 NT$25～30、US$1.29～1.99、¥3～5），還是用現在的價位？
4. **英文台詞翻譯方式**：模型批次翻譯＋抽樣校對，或找人工翻譯？
5. **開發工具**（骨架控制、動作標籤、Gallery、Studio）是否維持中文、不納入在地化？
6. 公司與稅務目前是中國制度：短期維持「同一套簡化制度、參數依市場」可以嗎？

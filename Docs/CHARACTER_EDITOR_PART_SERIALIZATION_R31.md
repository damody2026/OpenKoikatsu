## 計畫

1. 使用與 Live Open 共用的 CPU／GPU 請求判定，修正首次載入尚未初始化模式時漏做背景骨架預備；不可新增另一套判定或改變 CPU 模式。
2. 原生單欄 patch 使用部件範圍的資源拆分，跳過必定保留自 base 的全域骨架、動態、手勢及原始來源貼圖池之複製／序列化；完整輸出路徑保留原介面與格式。

4. 增加單欄各階段計時，區分來源讀取、context、擷取、序列化、patch、封裝及保存；建置、UE 契約與關閉 trace 的 GUI 嚴格驗收。

仍保留 100 ms／持續 60 FPS 斷言，不把階段微基準或單次功能成功當整體完成。

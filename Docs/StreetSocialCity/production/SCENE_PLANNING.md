# 整個世界場景視覺規畫

目前為122棟、427層、1,300個主要互動單元。模型製作保持暫停。

## 九個視覺區域與生活路線

- 整個世界鳥瞰：跨區步行與騎車、校園—商街—百貨—飯店生活路線、山林—河岸—海灣休閒路線。
- 大學校園整體：上課、實驗與系辦洽詢、圖書館閱讀與研究、社團活動、運動與宿舍休息。
- 學生商店街：購物、點餐、閱讀、洗衣、美容與自行車維修、民宿住宿與溫泉休息。
- 百貨與辦公區：百貨每層8個店面，共80個主單元、餐飲與娛樂、辦公、會議與創業服務。
- 豪華飯店與文化生活區：飯店入住、睡眠、餐飲與溫泉、文化展示、社區活動、夜市逛街與戶外表演。
- 住宅與交通站：返家、睡眠與共用生活、公車候車與換乘、自行車停放與租借。
- 河岸與濕地：散步、慢跑、騎車、釣魚、野餐、賞景、營位住宿與露營活動。
- 北山森林與小神社：登山散步、神社參訪與休息、高處觀景。
- 南側海灣與沙灘：沙灘散步與休息、海景拍照、河口自然觀察。

## 商街與逐店轉繪

商街包含96棟、四排店屋及兩條相向步行街，南側新增S49–S96。百貨10層，每層8間主要店面，合計80店。逐店先使用Grok圖稿，再核讀並校正SVG，百貨陳列已分散於各區。

建築外框與每層室內共用同一長寬，只扣0.2m牆厚。一般門1.2m、正門2.4m、室內走廊淨寬2m；每層有樓梯、電梯、廁所與1／5／10m比例尺。

全世界及商街提供Grok材料轉繪的原生SVG，保留獨立建物輪廓及正式文字。原始圖片的合併屋頂、錯誤院落、層數及新增背景建築都不直接描成尺寸圖。

台灣／中國用途案例及限制保留在building-references.json與逐店研究登錄；照片沒有標示的公尺，不反推為量測值。原始圖稿生成輸入與校正後SVG設計分別保存並綁定SHA。

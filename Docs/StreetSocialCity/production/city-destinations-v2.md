# 大學城景點採加法

## 使用者修正後的方向

保留原有建築風格，在各區增加值得停留、散步、逛街及拍照的物件。不要把所有牆面改成同一套淺底、色帶或相近配色。本輪依指示不重拍地圖，不把上一版截圖當成目前成果。

`city-art-v1` 的 728 個批次牆面綁定已還原至不可變原生基線；保留先前增加的 670 個入口／休憩擺設、122 處入口照明、草地及水面改善。交通站、文化中心、北商店街、宿舍等原有牆面不再覆寫。

## 資產流程

1. `Tools/build_street_city_destinations.lua` 記錄每件用途、預定區域、真實高度、優先面數與提示詞需求。
2. Chrome 的 Tripo **Model** 模式逐件提交，2K、PBR、生成上限30,000三角形；原生下載成功後確認資料夾中的 GLB，記錄工作識別。
3. `Tools/prepare_street_city_destinations.lua` 以 Blender 等比例縮放、落地，保留原始 PBR／UV。使用 `E:/Paper/instant-meshes-rs/target/release/instant-meshes.exe` 重建網格。
4. 幾何檢查拒絕時保留收據，記錄參考拓樸修復；薄葉／枝條需要較高預算時，在每件最多30,000三角形內調整並記錄原因。四邊形提取寫出失敗時改同一 Rust 程式的三角模式。沒有通過的模型不能匯入。
5. `dest_import` 逐件驗證當前 remesh 程式雜湊、來源與結果雜湊，再匯入 Unreal、保留 PBR 並建立100%／35%／10%三階LOD。大型拱門碰撞使用LOD0複雜碰撞，避免遠景簡化封住可穿過的孔洞。
6. `dest_install` 在所屬區域35m範圍內尋找位置，檢查建築、道路、水域、地面高差、既有物件及入口帶；主物件之間至少保留2m外接範圍間隙，配件只嘗試局部組合位置，不向其他區域亂散。
7. 保存後另開 Editor，`dest_verify` 同時核對原城與新景點的資產、材質、尺寸、LOD、實例位置、可見性、入口掃掠及正式地圖雜湊。

## 報告與限制

輸出在 `output/street-social-city-production/city-destinations-v2/`，包含計畫、30個工作識別、下載／remesh來源證明、原生匯入與配置收據、檢查結果及位置向量圖。

本輪不新增遊戲互動、不重拍地圖，也不宣稱已完成新版整體畫面觀感驗收或目標硬體FPS量測。幾何修復及較高的保形面數均須如實保留在收據，不能只報「程式有執行」。

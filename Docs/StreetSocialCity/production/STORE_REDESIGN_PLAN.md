# 全店面重製執行計畫

範圍：S01–S48 街邊建物（含 S18 民宿、S19 溫泉會館）及 M1 80 間店。

1. 逐店綁定台灣／中國實例，保留來源、照片、已知尺度及未知事項。圖片下載成功不等於已看過，也不等於照片具有量測尺度。
2. 按店型配置展示、候客、工作、收貨、儲藏、濕區與私密空間。室內外共用一份公尺幾何，走道至少 2m；一般門 1.2m、正門 2.4m，門扇畫開啟弧線。
3. 將造型拆成可製作的零件：店招、遮陽、玻璃門窗、展示架、商品、設備、座椅與牆面裝修；不能把有內容的物件當作實心盒子交付。
4. 以 Grok Build 畫店型示意，逐張檢查。生成圖不能自行改變電梯、樓梯、廁所、牆與通路；有差異就記錄退件，不能以生成成功充當幾何通過。
5. 更新 SVG、逐層計畫、拆件清單、地圖及索引；實際控制模型核對外框、開口、設備和通路。
6. 最後驗收目前功能；實際 Tripo 成品及遊戲導航保留獨立狀態。

執行結果以 [128 店驗收](store-redesign-acceptance.md) 與 [逐店審查頁](store-review.html) 為準。48棟店屋及80間百貨店皆有研究來源、用途設備與尺寸資料、Grok三欄示意及逐張差異紀錄；前三間店另有目前控制模型渲染的36個固定尺寸視角。

這一輪完成研究、規畫、控制模型及圖稿檢查。原始Grok圖的錯誤幾何不核准；逐店製作指引保留強制修正，正式Tripo模型和遊戲通行仍須後續製作與驗收，不能把控制模型當成成品。

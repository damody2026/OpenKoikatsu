# 活動邀請紀錄與交談額度

## 實作計畫
1. 以 APNG 穩定身分保存邀請冷卻；吃飯接受或拒絕後，當日不可再次提出。同行不設每日次數限制，但須剩餘至少兩次交談額度。
2. 完整語音回應完成後，以現有原子存檔交易扣一次額度並保存紀錄，成功後才派送活動；回應尚未完成時取消、缺少語音、存檔失敗不派送活動也不扣額度；回應已保存後再退出活動不退款。
3. 使用既有保存與日期冷卻機制，不建立一卡一份規則、不新增特化資源。下次啟動仍保留紀錄；場景既有次日操作解除冷卻。
4. 正式 Development 場景測試五種性格的接受／拒絕、取消、讀檔、重複邀請阻擋、隔日恢復與身分隔離；當前功能驗證成功後才更新公開啟動版本。完整人工驗收仍留最後。

## 與原作的差異必須明示
原作 TalkScene.CommandFunc 在活動指令開始時 DecreaseTalkTime(1)，ADV 完成後加入 heroine.talkCommand；Info 的吃飯條件檢查 command 3，而同行只檢查時間與追隨條件，沒有 command 4 的重複限制。Heroine.PopInit 清除紀錄，由 ActionScene.NPCLoadAll(bool) 呼叫，Cycle.MapMove 的配置流程會呼叫；不能稱為完全相同的每日重置。此場景採用既有遊戲日期作重置界線，並將扣額度延後至成功完成回應，以保持已實作的取消不提交政策。

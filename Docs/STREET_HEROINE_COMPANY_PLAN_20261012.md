# 女主開公司、雇用男主、雙方互租房產　計畫（2026-10-12）

需求：超有錢的女主也可能自己開公司、租店面或辦公室做生意，甚至請男主去工作；男主也可以做類似的操作。
照「列出計畫後直接實作」執行。

## 1. 原則

- **同一套公司引擎**：玩家公司和女主公司共用不動產、人力市場、月結、倒閉的規則。差別只在誰付錢、誰做決定：玩家公司是玩家按按鈕，女主公司由她的規則決定。
- **同一個市場**：每個店面、每塊空地同時只能屬於一家公司。被女主租走的，玩家就租不到，反過來也一樣。
- **對稱**：
  - 玩家可以替女主的公司打工，女主也可以替玩家的公司工作（原本就有）。
  - 玩家可以把自己的房產租給女主開店，女主一樣可以租別人的地方。

## 2. 女主什麼時候開公司（每天判斷一次）

| 條件 | 值 |
|---|---|
| 資產（現金＋存款） | ≥ ¥150,000 |
| 能力（profile occupation.competence） | ≥ 50 |
| 沒有欠款、沒有在玩家公司上班 | — |
| 每天機率 | 6%，資產每多 10 萬再加 2%，最多 15% |

**業態**：
- 喜歡的地點有咖啡廳或甜點店 → 咖啡館。
- 能力 ≥ 70 → 辦公室。
- 其他 → 店舖。

**據點的選法**（從同一個市場挑，選人潮最高、她負擔得起的）：
- **辦公室**：租現有建築裡的辦公單位。
- **店舖、咖啡館**：
  - 優先租玩家掛出租的完工建築，同一業態優先。
  - 沒有的話，就租或買一塊空地自己蓋。資產 ≥ 地價＋造價＋半年支出才買地，否則租地。
- **錢的來源**：資本 ¥50,000 和開店費用都從她的錢出。
- **名稱**：「{她的名字}的{咖啡館／工作室／小店}」。
- **公告方式**：開店時會產生流言、寫進她的專屬歷史。有交情的話，她會傳訊息告訴你。

## 3. 女主公司的經營

- **人力**：每週從求職者中錄用，直到容量的一半（規則用的分數同玩家的面試）。士氣、離職規則一樣。
- **營收**：同一套營收公式。玩家在她那裡打工的時數也算進產值。
- **月結**：
  - 營收進她的存款，房租、薪水、稅從她的錢付。
  - 付不出來的處理和玩家公司一樣：欠租會被收回、欠薪會有人離職、資不抵債就倒閉。
- **擴張**：連續 3 個月獲利，而且資產足夠時，她會開第二個據點。
- **收掉**：連續 3 個月虧損就自己收掉，退押金、資遣員工。倒閉或收掉都會寫進她的歷史並產生流言。
- **她自己的一天**：平日的上班行程改到她的總部，身分是老闆。她會在自己的店裡做事（站在櫃台，或坐在辦公桌前）。

## 4. 她請男主去上班

- **時機**：她有公司、和男主是朋友以上、好感 ≥ 40 或信任 ≥ 45、男主還沒在她那裡上班。每週一判斷，機率 25%。
- **條件**：時薪 = 職位基本月薪 ÷ 176 × (1 + 好感 / 200)，平日 10–18 排班。
- **送達**：她用 AI 寫訊息邀你，內容依她的理由（缺人、想多見你等）而定。邀約顯示在「我的公司」App 的「工作邀請」，有「接受」「婉拒」兩個按鈕。
- **接受後**：
  - 她的公司會變成打工系統裡的一份工作，排班、上班、早退、評價、被開除都沿用現有流程。
  - 薪水從她公司的帳上付；她付不出來時，你會拿不到，她會記得。
  - 你上班的時數會提高她的營收。
- **辭職**：可以在工作清單辭職。她會記得，好感小降。

## 5. 玩家當房東

- **掛出租**：自有的完工建築或店面可以設定「出租給別人（月租 X）」。被租走後玩家不能使用，也不算玩家公司的容量。
- **租約**：女主的公司租下時，雙方都有紀錄。每月 1 號她付租金給你（記在你的帳務）；欠 2 個月就收回。
- **收回與賣出**：玩家可以「收回」，下個月生效，她會不高興並記得。可以帶租約賣掉，賣價依市價，租約隨房產轉給買方。

## 6. 讓女主知道

提示詞裡會加入她自己的公司資訊（業態、地點、員工、盈虧），以及「你在她公司打工」或「你租她的店面」這類關係。

## 7. 存檔

- 新增 `HeroCompanies[]`：老闆的 id、名稱、業態、成立日、Estate（同玩家公司的結構）、連續盈虧月數、給玩家的邀請（時薪、職位、到期日）、玩家累計工時。
- `FOKStreetHolding` 新增：`Landlord`（房東：空字串為市場，"player" 或女主 id）、`Tenant`（房客公司）、`LeaseRent`（掛出租的月租）。
- 舊存檔讀得進來。

## 8. 介面

- **「我的公司」App 新增「別人的公司」分頁**：列出每位女主的公司（名稱、業態、地點、員工數、你在這裡的工作），可以導航過去。
- **工作邀請**：接受或婉拒；已經在她那裡上班的，可以辭職。
- **不動產分頁**：自有房產有「出租給別人」和「收回」按鈕，並顯示房客。
- **市場**：已被別人使用的地方顯示「XX 的公司使用中」，不能租買。

## 9. 驗證

新增 `-StreetSocialHeroCompanyTest`，依序跑：

1. 給女主 1 大量資產，讓她開店（租空地或租玩家掛出租的建築）。
2. 她錄用員工，月結後她的存款改變。
3. 她提出工作邀請，玩家接受；檢查打工系統裡出現這份工作，結束一次班後她的公司付了薪水。
4. 玩家把一棟完工建築掛出租，另一位女主租下；月結後玩家收到租金。
5. 讓女主連續虧損 3 個月，確認她收掉公司、員工資遣、押金退回。
6. 存檔讀回後所有欄位一致。

測試結束後還原存檔。

## 10. 中國五險一金與稅（2026-10-12 追加）

假設主角在中國大陸。費率都放在 `property.json` 的 `china` 區塊，可以直接改。

| 項目 | 規則 |
|---|---|
| 繳費基數 | 薪資夾在 [1500, 30000] × 月數之間；打工按工時折算月數（176 小時 = 1 個月） |
| 個人負擔 | 養老 8%、醫療 2%、失業 0.5%、公積金 7%（合計 17.5%） |
| 公司負擔 | 養老 16%、醫療 8% + 生育 0.8%、失業 0.5%、工傷 0.4%、公積金 7% |
| 個人所得稅 | 累計預扣法，每月免稅額 5000，七級累進（3%～45%） |
| 增值稅 | 小規模納稅人，營收 1% |
| 企業所得稅 | 年利潤 300 萬以內 5%，超過 25%；虧損可結轉抵減 |
| 金額取整 | 每一項各自四捨五入到元 |

套用的地方：
- **男主打工（任何雇主）**：下班時扣五險一金和個稅，薪資通知顯示「扣五險一金 ¥x、個稅 ¥y，實領 ¥z；公積金 +¥w」。全年累計值記在男主公司帳本的 Estate 裡（TaxYear、YtdIncome、YtdSocial、YtdTax、HousingFund、PensionPaid），公司 App 頂端顯示。
- **女主打工、女主當員工**：領到的是稅後實領（`OKStreetNetPay`）。
- **公司（男主的與女主的同一套 `EstateMonth`）**：每月依序繳增值稅，薪資再加公司負擔的五險一金，最後算企業所得稅（含虧損結轉）。
- **男主在她公司打工**：由她的公司付薪資加公司負擔部分。

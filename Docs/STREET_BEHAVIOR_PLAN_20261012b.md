# 街頭行為改善計畫・第三輪（2026-10-12）

來源：第二輪實作後的全遊戲盤點。這一輪以「上一輪新系統的 bug 與邊界情況」為主。
照「列出計畫後直接實作」執行，錯誤記在 `STREET_ERRORS.md`。

## A. 會壞存檔或讓人卡住（先做）

| # | 問題 | 修法 |
|---|---|---|
| A1 | 同一天重開遊戲會重排行程，接送約定重複加入存檔 | `AddAppointment` 對同種類、同女主、同時間去重（通用） |
| A2 | 逾期的托付提醒讓每晚都不能睡、N 要按兩次 | `AppointmentBefore` 只算需要到場的約定（排除 entrust） |
| A3 | 小睡／過夜的動作準備逾時後，女主一直卡在「和玩家忙」 | 逾時時完整收尾：兩人恢復、清掉 SleepGirl、SleepGirl2、SleepNap、Held |
| A4 | 歷史檔只增不減；她的日常（吃飯、打工、跑腿、每日摘要）全寫進去 | 載入時超過上限就重寫成最後 2000 行；日常類事件只進記憶、不進歷史 |
| A5 | 歷史序號用 double 存，重載後精度不足 | 序號改存字串 |

## B. 錢與時間算錯

| # | 問題 | 修法 |
|---|---|---|
| B1 | 女主打工中被緊急行程打斷時領全薪，班結束再領一次 | 薪水依實際在班的分鐘數，按「人＋日＋班次」記錄已付金額 |
| B2 | 緊急吃飯、休息會打斷上課、打工、約定；洗澡開始後不管固定行程 | 固定行程中只在需求極低（< 5）時插隊；固定行程開始時洗澡結束 |
| B3 | 活動中已經在購物車結帳，活動結束又照菜單再收一次 | 記錄活動期間有沒有結帳，有就不再收餐費 |
| B4 | 「各付一半」會讓玩家錢變負數；都沒錢時免費 | 先檢查他付得起；都付不起時記成他欠的錢（玩家欠款） |
| B5 | 活動結算跳時間會跳過約會 | 跳到最近的約定前 5 分鐘為止 |
| B6 | 接吻、擁抱被結算成「一起拍照」；外出的活動 id 殘留到下一次 | 活動開始時記下是不是親密姿勢；只有真正開始的活動才記 id，其餘清掉 |

## C. 手機與面對面的競態

| # | 問題 | 修法 |
|---|---|---|
| C1 | 講電話或傳訊息時，有人走過來，「在你面前」的開場白送給了手機那頭 | 遠端模式中，走過來、約會到場、她的親密願望都延後 |
| C2 | 掛電話時回覆還在路上，回來後被當成面對面：念出來、開始外出 | 送出時記下「遠端」，回覆依送出時的狀態處理 |
| C3 | 外出、活動、同行時可以打電話，掛斷後把面對面的對話也關了 | 有其他人和他在一起時不能打電話；掛斷只在沒有面對面對象時才關對話 |
| C4 | 她自己傳的訊息在她就站在面前時也會送出；待送訊息不存檔 | 她在身邊 10 m 內就改成走過來說；待送訊息存進 `phone.json` |
| C5 | 遠距離的「想他」訊息沒有上限，每 2–10 分鐘一次 API 呼叫 | 每人每天最多 3 則主動訊息、間隔至少 30 遊戲分鐘；同一人未接後的回訊冷卻 |
| C6 | 面對面時她不記得剛傳過的訊息 | 面對面時也帶入最近 3 則手機往來；接送請求寫進記憶 |
| C7 | 提示詞裡的近況被她自己的日常洗掉 | 優先放和他有關的事件，日常最多一則 |

# StreetSocial 剩餘功能實作計畫

2026-10-07，使用者要求繼續 Grok Build 平行完成。維持一男五女、新街區、APNG runtime、背景處理、60 秒載入目標與既有畫質；最後再完整驗收。

1. Grok 規則工作：追查 KKS 分支選擇、偏好、條件與關係事件；提供來源可追溯的通用 API、持久冷卻／旗標及測試。未支援原世界條件不當作 true。
2. Grok 共用資料工作：補分支上下文、開場／道別／拒絕、關係命令和表情／姿勢映射；輸出可攜音訊參照，不依賴玩家安裝 KKS；保留字幕與多段音訊精確對應。
3. Grok runtime 工作：有界的多角色私人 action stream、取消／代次安全及背景預暖，保證男女可同時表演，仍共用 4 GiB 預算。
4. 主代理場景整合：真正播放開場及道別、不消耗其話題次數、不附加話題獎勵；可取消；中文／日文切換；逐步接入關係事件、分支 UI 與表演，不使用單一卡片例外。
5. 主代理獨立验证：編譯、真實 catalogue 自動測試、五名 NPC 各三類話題與開場／道別、語音嘴型、取消與存檔。每次異常先修根因再重測。
6. 最後完整驗收：正式視窗操作、內容覆蓋、相同鏡位 CPU／GPU、冷暖啟動與幀時間、陰影警告、長時間／跨次啟動。保留原百人 CMD，不把六人性能冒充百人。

Grok 工作檔案責任各自分開；主代理負責讀差異、整合及最終證據。CLI 回合上限、進度摘要或未結束背景工作不視為任務完成。

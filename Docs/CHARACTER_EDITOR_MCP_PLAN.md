# 人物編輯模式 MCP 完整實作計畫

日期：2026-10-09。需求：所有人物編輯模式的參數均能由外部 AI 查詢與調整；主要使用情境是依正／側／背三視圖反覆調整並保存接近目標的身形。頭髮與衣服仍須提供既有編輯能力，但素材相似度不是身形驗收條件。

## 1. 範圍與完成定義

- 原生身體 44 項、臉部 52 項，全數提供穩定名稱、讀寫、範圍、預設與重設。
- 骨骼控制定義（目前 1,192 項）、左右獨立／同步、XYZ 縮放、長度、位移、旋轉與服裝限定修飾。
- 身體物理、腹部形變及其開關／預設、所有卡片詳細屬性（顏色、布林、數值、配件綁定、模組屬性）。
- 外觀目錄及素材選擇：臉、頭髮、服裝、配件及新增配件槽；依目前素材庫動態列舉，不硬編碼完整素材清單。
- 表情、嘴型、眼睛／眉毛、眨眼、視線、手勢、動畫與動畫參數、服裝狀態、服裝切換。
- 編輯模式提供的其餘可編輯控制（文字、選單、開關、數值、顯示設定），建立自動盤點與可讀寫適配器，避免日後新增 UI 卻漏接 MCP。
- 攝影、取景、區域截圖、固定三視圖、快照與角色卡另存。
- 動態角色不支援的骨骼／素材必須明確回報原因；不得把無效果的寫入回報為成功。未知二進位模組資料保持原樣，不能宣稱任意第三方插件資料皆可編輯。
- MCP 只作用於人物編輯模式；其他場景的控制不混入。操作按實際編輯能力區分資料修改、預覽狀態與命令。

## 2. 架構

外部 MCP 客戶端 → Python 標準函式庫 stdio JSON-RPC 服務 → 本機原子檔案信箱 → Unreal game thread → 現有 CharacterController／Rust Session／卡片寫入流程。

- 啟動遊戲加 `-CharacterMCP` 才接收控制；`-CharacterMCPDir=` 可隔離不同執行個體。
- 不開網路監聽埠；stdio 輸出只含協定訊息，診斷走 stderr。
- 所有 UObject／渲染操作都在 game thread；等待採非阻塞狀態機。
- 請求使用唯一 ID、期限、人物 session 及 revision；拒絕過期人物與過期版本。
- 寫入前整批驗證；回報 applied／staged／busy／error。失敗須可回復，非同步更新不得先回報已完成。
- 本機檔案信箱只是內部傳輸；外部 AI 使用的是標準 MCP tools/list、tools/call 及 image content。

## 3. 參數目錄與工具

`character_state`、`character_load`、`parameters_list`、`parameters_get`、`parameters_set`、`parameters_reset`、`editor_controls`、`editor_control_set`、`editor_action`、`appearance_catalog`、`appearance_select`、`appearance_add_accessory`、`character_apply`、`snapshot_create`、`snapshot_restore`、`capture_configure`、`capture_region`、`capture_views`、`character_measure`、`character_save`。

每項描述包含 key、中文 label、category、kind、value、default（有可靠來源時）、min/max、unit、choices、supported、requires_apply、persistence。骨骼使用骨名與軸向組合的 ID，不使用 UI 排列索引；動態控制標示其作用範圍。

- 參數目錄可搜尋、分頁及指定 key 讀回，避免一次傳回數千項。
- UI 適配器沿用既有回呼，保留動畫準備、素材套用與服裝快取語義。
- 批次形變合併，避免每改一項便重載角色；顏色／素材等耗時操作以作業狀態等待。
- 另存採新檔路徑，保留完整 KKEx、未知欄位與獨立資源契約。

## 4. 三視圖與量測

- 固定正／側／背視角，共用焦點、尺度、地面基準與解析度；支援左右側面。
- 優先正交攝影，保留透視；固定 A／T 姿勢、表情、動畫與物理條件。
- 可隱藏髮／衣／配件，以純色背景和身體輪廓觀察幾何。
- 彩色 PNG、局部區域、人物遮罩／標記分階段驗證。回傳拍攝參數與實際像素尺寸。
- 身形改動期間鎖定鏡頭，不能逐張自動縮放而隱藏比例差異。
- 等形變、骨骼、鏡頭與渲染完成才截圖；三張圖對應同一人物 revision。
- 模型端輸出身高、包圍盒與可用骨骼標記／比例；進階身體截面量測需排除髮衣配件。
- 參考圖預處理／遮罩／關節標記由外部 AI 或後續工具完成；無真實身高時只能還原比例，照片的寬度不等於真實圍度。

## 5. 外部 AI 調整流程

1. 載入人物，讀取支援能力與完整參數目錄，建立 baseline 快照。
2. 對齊參考三視圖，固定姿勢、攝影條件與比較區域。
3. 調整身高、頭身比、肩寬、軀幹與腿長等整體比例。
4. 調整胸腔、胸腰臀、腹部與四肢截面。
5. 使用骨骼修飾處理原生參數不足的局部與左右差異。
6. 批次提交、等待穩定、擷取三視圖、比較、保留最佳快照或回退。
7. 完成頭臉及細節，保存角色卡、參數與三視圖；重新載入確認一致。

提供小幅擾動參數與還原的範例，使外部 AI 能估計參數敏感度。完整自動視覺最佳化與任意模型新增 morph 不是僅靠 MCP 介面即可保證的效果，另以可重現資料驗證。

合成還原先量測實際可達誤差再定門檻；候選門檻為主要比例約 2%、平均輪廓偏差約身高 1%，不可把未驗證門檻當作已達成結果。未知模組／無法表達的局部形狀必須明列限制。

## 7. 現況

### 第二階段執行計畫（依 2026-10-09 繼續完成指示）

1. 匯出目前身體／頭部實際形變後頂點、解剖表面三角形與骨骼標記；GPU／procedural 分別沿用原生幾何，排除衣髮配件，禁止以 padded bounds 替代。
2. 三角形平面交線量測：回報閉合截面及各自周長、寬深、平面高度與有效性，避免把手臂合併成腰圍。
3. 以幾何建立固定投影的三視圖身體遮罩；支援透明圖、明確二值遮罩、可設定背景的參考圖。一次對齊尺度與平移後固定比較，提供輪廓／區域誤差。
4. 實作可中斷、有評估上限、保留最佳值、可重新啟動的通用數值搜尋。參數由目錄查詢，允許外部 AI 指定身形／臉形／骨骼組合；不硬編碼單一角色或目標解。
5. 提供 MCP 工具與命令列操作、敏感度估計與持久化報告。記錄取消／例外並保留最佳候選，不以中斷當成功。
6. 先用不同幾何和影像測試演算法，再真實角色產生未知合成目標，擾動參數後自動還原；重新保存／開啟及完整現有功能回歸驗收。

錯誤紀錄：[CHARACTER_EDITOR_MCP_ERRORS.md](CHARACTER_EDITOR_MCP_ERRORS.md)。精度以本次實測呈現；有限輪廓無法唯一決定所有參數，停止條件必須明列。

已實作 31 個 MCP tools。測試卡可查詢 4,300 項人物資料參數與 49 個其他編輯控制；除編輯、截圖、快照與保存外，已加入實際網格／骨骼標記、截面、獨立三視圖遮罩、參考對齊、敏感度、比較與背景搜尋。搜尋有次數／時間上限、取消、最佳值保存、續跑及持久化作業狀態。

正式建置 build-r21、Python 16 項測試及最新 Registry automation r3 已通過。完整實機驗收 LiveR12 的 20 項全部通過，包含全原生參數、真實截圖、外觀套用／保存／重開、精確幾何／截面／遮罩、參考對齊、敏感度與背景搜尋。合成目標的固定投影輪廓誤差由 0.132811 降至 0.001924（降低 98.55%，9 次評估），最佳結果保存與重開後參數一致。NumPy 初始化與參考對齊問題均已修正並由回歸測試覆蓋。覆蓋細節與證據見 [CHARACTER_EDITOR_MCP_COVERAGE.md](CHARACTER_EDITOR_MCP_COVERAGE.md)，啟動設定見 [README](../Tools/character_mcp/README.md)。

驗收依最新指示確認當前功能成功實作，使用全原生參數讀寫、代表性骨骼／屬性／控制及未知合成目標還原測試；不將所有角色／任意第三方模組的窮舉視覺測試當作本次停止條件。任意照片的姿勢／透視反推、語義分割、超出現有 morph 的幾何與參數解唯一性仍屬輸入及模型限制。

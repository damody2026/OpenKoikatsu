# 設施通用生命週期

1. 所有設施先在runtime背景prewarm角色私有動作；準備時停留街區，不提前把角色放上床／椅子。共用房間道具在進入前隱藏。
2. 預暖ready且clip相符後才play並切入自建房間。快照保存實際離開街區的位置、鏡頭及滑鼠。不得以尚未就緒姿勢顯示女角。
3. 右側提供準備取消／離開設施。準備60秒上限與使用時間分開；使用不因準備時間被提早中止，直到玩家退出。角色失效或動作遺失則退出。
4. 三設施實景probe：準備取消不移位、重試、實際私有動畫／骨骼、過60秒準備時鐘仍能使用、退出位置／鏡頭／滑鼠／道具／存檔恢復。專用測試成功後既有回歸，才更新原CMD。

維持runtime APNG、共用來源曲線與自建房間；本輪不聲稱完成走到實體設施入口、完整施術者動畫、原作邀請或全部世界。

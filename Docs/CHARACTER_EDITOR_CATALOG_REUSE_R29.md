# 原作素材目錄共用 R29

## 計畫

1. 原作素材清單改用有限大小的共用不可變資料快取；單欄飾品直接借用共用清單，其餘既有入口保留值資料介面。
2. 使用檔案變動通知使快取失效，包含新增、移除、改名與同大小內容更新；不能用固定時間到期冒充有效性。通知不可用、目錄不存在或讀取中有變動時，保守重新解析且不發布不穩定快取。
3. 空飾品且無來源解析紀錄時，在素材清單載入之前返回；不改變有解析紀錄的模組優先順序。
4. 測試命中、失效、不同目錄、舊 Arc 壽命、容量限制與不可用通知；再跑真實單欄完整來源契約、正式卡片新增／重置、建置與 GUI 驗收。
